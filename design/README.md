# Design files

Start with a photographed sketch and a measured layout. Add CAD only if it helps the build.

For each revision, record dimensions in millimeters, material and thickness, device orientation, ventilation paths, cable access, and what changed from the previous version.

Suggested filenames:

- `v01-layout-sketch.jpg`
- `v02-measured-layout.pdf`
- `v03-final-drawing.pdf`

These are naming examples; no drawings have been created yet. Keep editable design sources alongside exported drawings when available.
